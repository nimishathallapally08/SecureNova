# Project 1: Threat Model

This project documents the identity and access risks in the SecureNova AI
chatbot. It combines an identity inventory, STRIDE analysis, attack trees,
risk scoring, and MITRE ATLAS mappings. The project report is
[Project1.pdf](./Project1.pdf).

## Deliverables

- `identity-inventory/` — identity inventory workbook and Threat Dragon model
  JSON.
- `attack-trees/` — three attack trees covering API-key exfiltration, agent
  identity spoofing, and RAG chunk poisoning. PNG exports accompany the
  editable Draw.io diagrams.
- `stride-matrix/STRIDE_Matrix.xlsx` — STRIDE analysis across the modeled
  data flows.
- `risk-register/Risk_Register.xlsx` — ranked risks with likelihood, impact,
  and ownership.
- `atlas-mapping/atlas-technique-ids.md` — rationale and source links for the
  mapped MITRE ATLAS techniques.
- `links/screenshots/` — evidence images referenced by the project report.

The diagrams and workbooks are source artifacts; the PDF is the consolidated
report. No executable application or setup step is required.
