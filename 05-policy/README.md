# Project 5: Policy and Compliance

This project contains the SecureNova identity-security policy and its
compliance mapping:

- [AI Identity Security Policy](./AI_Identity_Security_Policy.docx) — the
  policy document.
- [Compliance Mapping](./Compliance_Mapping.xlsx) — the accompanying
  spreadsheet mapping policy controls to compliance requirements.

These are review and governance artifacts, not executable software. There is
no application setup or runtime command for this project.
